# 🔐 Password Generator

A clean, dark-themed password generator built with HTML, CSS, and JavaScript.

## Features

- Customizable length (6–32 characters)
- Toggle lowercase, uppercase, numbers, and symbols
- Shuffle algorithm — no predictable patterns
- Strength indicator (Weak / Fair / Strong / Very Strong)
- One-click copy to clipboard
- Recent passwords history (last 8)

## Files
project/
├── index.html
├── style.css
└── script.js

## How to Use

1. Select character types (lowercase, uppercase, numbers, symbols)
2. Adjust the length slider
3. Click **Generate Password**
4. Click the copy button to copy to clipboard

## Tech Stack

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript (no libraries)
